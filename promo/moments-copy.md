# Pickup 朋友圈素材

## 推荐朋友圈文案

我做了一个 macOS 菜单栏小工具：Pickup。

它用来把分散在 ChatGPT、Claude Code、Codex、Ghostty、飞书文档里的工作线索，按“项目”收起来。

以前我经常记得“我好像问过这个问题”，但忘了是在 ChatGPT、Claude 还是终端里。现在可以直接按项目看相关 session 和链接。

目前主要给自己用：
- 自动同步最近 7 天的 AI session
- 支持手动添加飞书/网页链接
- 可以隐藏没用的噪音 session
- 点一下回到原来的对话或链接

如果你也经常同时开好几个 AI 工具，应该会懂这个痛点。

## 更像产品介绍的版本

Pickup 是一个 macOS 菜单栏应用，用来按项目管理 AI 工作 session。

它不是新的 AI 工具，而是 AI 工具之间的“项目抽屉”：

- ChatGPT 对话
- Claude Code session
- Codex session
- Ghostty/终端上下文
- 飞书和网页链接

都可以挂到同一个项目下面。

## 评论区可用回复

**别人问：这是干嘛的？**

就是把各种 AI 对话和项目链接收纳到一起的小工具，解决“我到底在哪个工具里聊过这个”的问题。

**别人问：支持哪些？**

现在主要是 ChatGPT、Claude Code、Codex、Ghostty/终端，还有手动添加的飞书/网页链接。

**别人问：数据会上传吗？**

不会，数据存在本机 `~/.sessiontracker/data.db`。
